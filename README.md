# Data-Science-Project
This was a Kaggle-style project that I completed for my data science class (specific details omitted to keep things fair for new students). The project involved performing EDA (Exploratory Data Analysis) on housing data from Cook County, Illinois in Part 1. In Part 2, we created a linear model with the aim of predicting housing prices based on the data we were provided with. The main question we tried to answer here was whether the model being used for this purpose was "fair", and whether it truly benefitted the people it was supposed to help.

This project was completed in April 2026, and files were uploaded to GitHub in October 2026.
